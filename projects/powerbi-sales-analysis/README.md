# Sales Analysis Dashboard

Interactive Power BI dashboard analyzing sales performance across multiple dimensions.

## Features
- Comprehensive data model with relationships
- DAX measures for advanced calculations
- Dynamic visualizations

## Tools Used
- Power BI Desktop
- DAX
- Data Modeling
- ETL

## How to View
Download the `analysis.pbix` file and open it with [Power BI Desktop](https://www.microsoft.com/en-us/download/details.aspx?id=58494) (free).
